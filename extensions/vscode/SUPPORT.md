# Support

Use the repository issue tracker for reproducible defects:

https://github.com/fwtllh-png/CodeHelper/issues

Include the VS Code version, extension version, local Extension Host
platform, binary source, and redacted CodeHelper output. Do not attach credentials
or proprietary source code.

Dynamic support is currently verified on local macOS arm64/x64 workspaces.
Windows x64 has package-level static verification only. Remote SSH, Dev
Containers, Codespaces, WSL remote workspaces, and other `vscode-remote:`
workspaces are not supported.
