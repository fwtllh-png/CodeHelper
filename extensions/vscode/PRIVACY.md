# Privacy

The extension sends editor context only to the CodeHelper Runtime selected on the
local UI Extension Host. It does not embed analytics or advertising SDKs.

Managed binary update checks contact only the fixed release origins documented
by the project. Update receipts contain version, digest, channel, time, and
result; they do not contain source paths, prompts, credentials, or tokens.

Model provider and telemetry behavior is controlled by the separately installed
CodeHelper Runtime and its configuration.
