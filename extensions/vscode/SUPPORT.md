# Support

Use the repository issue tracker for reproducible defects:

https://github.com/fwtllh-png/CodeHelper/issues

Include the VS Code version, extension version, Workspace Extension Host
platform, binary source, and redacted CodeHelper output. Do not attach credentials
or proprietary source code.

Dynamic support is currently verified on macOS arm64/x64, Remote SSH Linux
arm64, and Dev Containers Linux arm64/amd64. Windows x64 has package-level
static verification only; WSL2 and public Codespaces are not dynamically
certified.
